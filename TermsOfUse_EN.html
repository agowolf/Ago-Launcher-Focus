6. Permissions and Data Use

To provide its features, the App requests the following permissions. The purpose of each permission is detailed in the Privacy Policy; this Section is a summary:

  • Location (approximate, ACCESS_COARSE_LOCATION): used to obtain local weather via approximate positioning; deniable — you may instead select a city manually.
  • Notification access (granted actively by the user): used to read metadata of the currently playing song (e.g., title) and display it on the home screen. The App only reads media-session metadata; it does not read your notification body text, and does not collect or upload your notifications or chat content.
  • Querying installed apps (scoped <queries>): as a launcher, used to list apps available for home-screen binding, to detect system default apps (dialer / camera / gallery / SMS / music), and to determine whether the App is the system default launcher; these queries are performed locally only, and no app list is uploaded.

  • Bluetooth (declared only up to API 30): used to show the on/off state of the home-screen Bluetooth quick icon; API 31+ no longer requires this declaration.
  • Vibration (VIBRATE): used for haptic feedback on long-press, dial, and other actions.

The App does not request READ_PHONE_STATE, does not use Device Admin or Device Owner mode, and no longer requests QUERY_ALL_PACKAGES (replaced by a scoped <queries> declaration).

Other than what is necessary to provide the features above, we will not access the data covered by these permissions for any other purpose. For details on data collection, storage, and (if any) sharing, the Privacy Policy prevails.

  2. Important behavior of Timer Lock — please read. Once a Timer Lock is active, it remains in effect until the set time expires. You can wait for the timer to end, or use one of the force-exit methods below. Please set a sensible lock duration and avoid setting excessively long timers.
  3. If you are locked out — force-exit / recovery. Because the App holds no device-level privileges, you can always regain full access to your device by any of these methods:
  • Clear app data: System Settings > Apps > Ago Launcher Focus > Storage > Clear data (this resets the App and removes the lock; you will need to reconfigure it afterward).

  • Android Safe Mode: reboot into Safe Mode (long-press the Power button, then long-press "Power off" / "Reboot to safe mode"); in Safe Mode, third-party launchers are disabled and you can reach system settings to clear data or switch launchers.
  • Uninstall remotely: on a computer, open play.google.com, find Ago Launcher Focus in your app library, and uninstall it remotely.
  • ADB (if developer tools are available): run adb shell pm clear ago.launcher.focus. Note: clearing data or uninstalling deletes all locally stored data (see Privacy Policy Section 6). The in-app Help & Feedback > User Guide also describes these recovery methods.

9. User Guide

9.1 Basic operations (Focus & Line)

  • Set as default home: after installation, set the App as the system default home (Home) in system settings to enable all home-screen features.
  • Open apps: Focus theme — tap the 6 edge dots around the dial; Line theme — tap the dock app icons.
  • Exit home: open Settings → tap the top "Set as default / Exit theme" button to jump to system home settings and switch launchers. If password lock or Focus Lock is enabled, you must enter the password before exiting.
  • Top-right quick icons: battery / settings (three-dot icon) / flashlight / calculator; long-press or tap the corresponding icon to use.
  • Weather: first use requests coarse location to obtain weather; you can manually select a city and switch weather conditions (sunny / cloudy / rain / snow).
  • Settings entry: tap the top-right three-dot icon to enter the settings page.

9.2 Focus-specific operations

  • Rotate the dial: swipe to spin the central dial; it snaps back with haptic feedback on release.
  • Hidden Apps (PRO): swipe the dial and the center circle blinks for 3 seconds; tap the center circle to reveal hidden apps.
  • Long-press to reorder: long-press any edge dot of the dial (about 1 second, with haptic feedback) to enter edit mode, and drag dots to swap positions.
  • Bottom music bar: shows the current song title (requires Notification access), an album progress ring, and play/pause and track buttons.

9.3 Line-specific operations

  • Turntable media controls: three media keys in the center of the dial — prev / play-pause / next. The outer ring of the center circle is the playback progress ring. Tapping the blank area outside the three keys opens the music app.
  • Swipe up/down to switch tracks: swipe up on the dial for prev, swipe down for next; you can select a swipe animation in Settings (slide rebound / flip / song-title slide, etc.).
  • Music rhythm mode: when music is playing, the dial's outer ring shows dynamic visual effects; select a rhythm mode in Settings (pulse ring / flow arc / radial spectrum / wave ring / breathing halo, etc.).
  • Dock reordering: long-press any dock app icon to enter drag mode, drag to the target position and release to reorder; the dock auto smooth-scrolls back to position after 1.5 seconds idle.
  • Custom buttons (L1-L3 / R1-R3): after enabling "Show side slots" in Settings, 6 customizable button slots appear on both sides of the dock (swipe left for L1-L3, swipe right for R1-R3). Unbound empty circles, when tapped, enter the app picker directly; once bound, they show the real app icon. You can enable "Lock hidden-app config" in Settings to prevent accidental changes.
  • Color schemes: the Line theme offers three color schemes — light-blue gray, warm white, night blue — switchable in Settings.
  • Theme switching: tap "More themes" in Settings to switch back to the Focus theme; both themes share all data.

9.4 Security & Focus

  • Focus Lock: when enabled in Settings, exiting the home screen requires turning off Focus Lock or entering the password.
  • Timer Lock: set a lock time period; the home screen auto-locks when the time is reached.
  • Change password: Settings → Security & Focus → set exit password (at least 4 digits).
