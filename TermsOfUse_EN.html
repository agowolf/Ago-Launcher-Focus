7. Focus Lock and Timer Lock — Risks and Recovery

  1. What these features do. The App offers optional "Focus Lock" and "Timer Lock" features to help you reduce phone distraction. Focus Lock, when enabled, requires you to either turn it off in Settings or enter your exit password in order to leave the home screen. Timer Lock keeps the App active as your home screen until a time you set. Both features rely solely on the App being set as the system default launcher (so it can handle Home and Back) — the App does NOT request Device Admin or Device Owner permissions, and does not provide a strong Kiosk mode that requires ADB to install.
  2. Important behavior of Timer Lock — please read. Once a Timer Lock is active, it cannot be cancelled before the set time expires — even by entering the correct exit password. You must wait until the timer ends, or use one of the force-exit methods below. Please set a sensible lock duration and avoid setting excessively long timers.
  3. If you are locked out — force-exit / recovery. Because the App holds no device-level privileges, you can always regain full access to your device by any of these methods:
  • Clear app data: System Settings > Apps > Ago Launcher Focus > Storage > Clear data (this resets the App and removes the lock; you will need to reconfigure it afterward).
  • Uninstall the App: System Settings > Apps > Ago Launcher Focus > Uninstall (you can reinstall it afterward from the Google Play Store).
  • Android Safe Mode: reboot into Safe Mode (long-press the Power button, then long-press "Power off" / "Reboot to safe mode"); in Safe Mode, third-party launchers are disabled and you can reach system settings to clear data or switch launchers.
  • Uninstall remotely: on a computer, open play.google.com, find Ago Launcher Focus in your app library, and uninstall it remotely.
  • ADB (if developer tools are available): run adb shell pm clear ago.launcher.focus. Note: clearing data or uninstalling deletes all locally stored data (see Privacy Policy Section 6). The in-app Help & Feedback > User Guide also describes these recovery methods.
